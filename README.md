# Новостная аналитика для Альфа-Бизнеса (хакатон)

## Структура
- frontend/ — сайт (сейчас есть кликабельный прототип prototype.html)
- backend/ — API
- agent/ — ИИ-агент и промпты
- data/ — профили компаний

## Формат данных
Общий формат — frontend/mock_data.json. Агент выдаёт такой JSON, бэк отдаёт, фронт рисует.
Поля меняем только после договорённости в чате.

## Правила
1. В main не пушим — только через Pull Request, потом кто-то из нас смотрит и мержит.
2. `.env` не коммитим!
3. Исходные CSV лежат локально в `data/raw/`, в git не попадают, а то их размер раздует репо и будет плохо.
4. mock_data.json -- пример того, какого вида должен быть JSON, который создаёт ИИ/МЛ после аналитики, передаётся в бэк и потом отображает фронт в виде карточки на сайте. Если что-то там поменяете, вся цепочка может сломаться

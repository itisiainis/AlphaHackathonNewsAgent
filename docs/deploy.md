# Развёртывание

Сервис — один Docker-контейнер (API + интерфейс). Ниже три способа: локально, Render, Railway.
Во всех случаях ключ модели задаётся только переменной окружения на стороне сервера: в репозиторий, в чаты
и в код страницы он не попадает (требование организаторов). Без ключа сервис работает: отбор новостей,
готовые разборы, расчёт эффекта и краткий разбор без выводов ИИ.

## Локально (проверка жюри)

```bash
cp .env.example .env          # по желанию: LLM_BASE_URL и LLM_API_KEY
docker compose up --build
```

http://localhost:8000 · проверка живости: http://localhost:8000/healthz · API: http://localhost:8000/docs

Данные (карточки, обратная связь, кеш ответов модели) хранятся в томе `cache` и переживают перезапуск.

## Render

1. Dashboard → **New → Blueprint** → репозиторий. Render прочитает `render.yaml`.
2. Введите секреты `LLM_BASE_URL` и `LLM_API_KEY` (поля помечены `sync: false` — значения не хранятся в репозитории).
3. После сборки откройте выданный адрес `https://<имя>.onrender.com`.

Бесплатный план засыпает без запросов; первый запрос после сна — около минуты. Кеш на бесплатном плане
не сохраняется между перезапусками: готовые разборы из `data/cards` загружаются заново при старте.

## Railway

1. **New Project → Deploy from GitHub repo** → репозиторий. Railway соберёт `Dockerfile` (`railway.json`).
2. Variables: `LLM_BASE_URL`, `LLM_API_KEY`, по желанию `LLM_DAILY_BUDGET_RUB=50`.
3. Settings → Networking → **Generate Domain**.

## Переменные окружения

Полный список — `.env.example`. Главное:

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `LLM_BASE_URL`, `LLM_API_KEY` | — | доступ к разрешённым моделям; без них — краткий разбор без ИИ |
| `LLM_DAILY_BUDGET_RUB` | 50 | дневной лимит расхода сервиса (ключ общий на команду, 500 ₽/день) |
| `RATE_LIMIT_PER_MIN` | 10 | платных запросов в минуту с одного адреса |
| `POST_LIMIT_PER_MIN` | 60 | любых изменяющих запросов в минуту с одного адреса |
| `COLLECT_ON_START`, `COLLECT_EVERY_MIN` | 1, 60 | сбор свежих новостей при старте и по расписанию |
| `COLLECT_TRIAGE` | 1 | разметка новостей моделью Gemma (~0,003 ₽ за пачку); 0 — только словари |
| `APP_TODAY` | — | зафиксировать «сегодня» для воспроизводимой демонстрации |
| `PORT` | 8000 | порт; облачные платформы задают сами |

## Перед публичным адресом

- Аутентификации нет: вход в интернет-банк смоделирован переключателями. Публичный адрес даём только жюри.
- Лимит расхода и ограничение частоты включены по умолчанию; расход виден на странице «Качество».
- Предрасчёт карточек, чтобы демонстрация не тратила бюджет: `python -m scripts.run_agent <компания> --top 3 --save`
  (скрипт сам остановится, если общий ключ команды за день израсходован больше чем на 300 ₽).
